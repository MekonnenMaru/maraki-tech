## Google AdSense vs Google Ads

They are different products and easy to confuse:

| | **Google AdSense** | **Google Ads** |
| --- | --- | --- |
| Who pays? | Google pays **you** | **You** pay Google |
| What happens? | Other companies' ads appear **on your site** | **Your** ad appears on Google search and other sites |
| Goal | Earn money from visitors | Get new clients |
| ID in the admin | `ca-pub-…` | `AW-…` + conversion label |

You can use one, both, or neither. Leave an ID empty to keep that service off.

## Recommended order

1. [Go live](going-live.md) on your domain with HTTPS.
2. Replace all sample content (admin **Overview** → checklist).
3. Set up [Analytics and Search Console](google-analytics.md).
4. Then [Google Ads](google-ads.md) and/or [AdSense](google-adsense.md).
